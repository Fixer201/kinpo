# Описание

Грамматический анализатор английского текста (English Grammar Checker).
Программа принимает файл в формате CoNLL-U (результат UDPipe-обработки)
и выводит список найденных грамматических ошибок с предложениями по исправлению.

(Подробнее см. Внешняя спецификация)


# Использование

Для запуска программы используйте следующую команду:

checker.exe <путь_к_входному_файлу> <путь_к_выходному_файлу> --lists <путь_к_lists>

Пример команды:

.\checker.exe input.conllu output.txt --lists .\lists


# Входные данные

Программа принимает текстовый файл в формате CoNLL-U
(результат разбора UDPipe — 10 колонок, разделённых табуляцией).


# Выходные данные

Выходной файл содержит список предложений с обнаруженными ошибками,
каждое описание ошибки включает:
- Номер предложения
- Тип ошибки (ID правила)
- Фрагмент с ошибкой и исправление
- Пояснение

Если ошибок не найдено, выводится "NO ERRORS FOUND".


# Требования

- Windows 7/8/10/11 (64-bit)
- Файл входных данных должен быть в формате CoNLL-U
- Папка lists должна находиться рядом с checker.exe или
  указываться через параметр --lists
